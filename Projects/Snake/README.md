## 📖 About

**Snake** is a modern take on the timeless arcade classic. Guide the green snake around the grid, gobble up red food to grow longer and rack up points, all while avoiding collisions with yourself — set to background music and satisfying sound effects.

---

## 🎮 Controls

| Key | Action |
|-----|--------|
| **W** | Move up |
| **A** | Move left |
| **D** | Move right |

---

## 🍎 Gameplay Elements

| Element | Color | Meaning |
|---------|-------|---------|
| 🟩 Snake | Green | Your controllable snake |
| 🟥 Food | Red | Eat to grow and score points |

- Each food item eaten = **+10 points**
- 🎵 Background music plays throughout
- 🔊 Sound effect triggers every time food is eaten

---

## ✨ Features

- Smooth grid-based snake movement
- Self-collision detection
- Score tracking with +10 points per food eaten
- Background music for immersive gameplay
- Dedicated sound effect on eating food

---

## 🛠 Built With

- **C++** — core game logic
- **SFML** — graphics rendering, input handling, and audio playback

---

## ▶️ How to Run

1. Make sure **SFML** is installed and linked in your build environment.
2. Compile the source file with your C++ compiler, linking against SFML.
3. Run the generated executable.
4. Use **W / A / D** to steer the snake and eat as much food as you can without colliding with yourself.
